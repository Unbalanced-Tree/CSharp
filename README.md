# CSharp
Project related to C# programming language. 
Each project has a README.md file that outlines the details. I have written [blogs](https://dev.to/unbalanced-tree) for some projects. Don't forget to check them out.
### - MediatRProject: Implemented Mediator pattern with MediatR NuGet package. 
### - WebApiWithDocker: Web API with Docker-compose.
### - Microservices: Microservices communication using Dapr and Docker-compose. 
### - InMemoryDb: In-Memory database with SQLite. Also a DB browser suggestion. 
### - FastReport: FastReport design and PDF generation. 
### - XUnitTesting: Unit testing with xUnit. 
### - MultipleLanguages: multiple language support AKA Localization. (Hindi, English).
### - GraphQL/ChocolateServer: Building GraphQL APIs.
